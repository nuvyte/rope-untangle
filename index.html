Swipe for more

One simple rule

Tap a rope

It reels back to its peg, but only if no other rope is lying on top of it.

Read the clues

Patches hide some crossings. Numbers on rope ends tell you how many crossings that rope is on top at.

Find the order

Work out which rope comes free first, then the next, until the board is clear.
